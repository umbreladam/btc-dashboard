Import exchange statements (PDF or CSV)

Supported: Coinbase transaction report (PDF) or transaction history CSV, Coinbase Pro fills and account statements (PDF or fills.csv / account.csv), CoinCorner GBP account statement (PDF or CSV), Kraken ledgers.csv or trades.csv, Strike account statement CSV, or the Satoshi native CSV (all types: buy, income, acquisition, sell, spend, gift, disposal, fee, transfer, lost; see README). Only BTC rows are imported (altcoins are ignored); deposits/withdrawals are transfers, not disposals. Files are processed only on this device. You'll see a preview first, and duplicates (including the same trade from a PDF and a CSV) are skipped.

Strike DCA (optional, read-only API key)

Optional. Don't use Strike? Set Frequency to Off and add your buys with Import (CSV) or Transactions → Add.

How to create a read-only Strike API key
  1. Sign in at https://dashboard.strike.me.
  2. Open the API Keys section and create a new key.
  3. Name it, e.g. BTC Dashboard.
  4. Tick only partner.balances.read (read account balances) and partner.rates.ticker (exchange rates). Leave every other permission unticked.
  5. Copy the key (Strike shows it only once), paste it below and press Save, then Test key.

With only these two permissions the key is read-only and cannot move, send or spend funds. It is stored only in this app's local database on your Umbrel and is sent only to api.strike.me.

Key material is write-only: after saving it is never shown again (not even here). You can rename, describe or relabel a wallet at any time; to change keys, remove it and add it again.

Where do I find my descriptor?

Multisig needs the descriptor (an xpub alone can't describe a multisig wallet). Accepted: wsh(sortedmulti(...)), wsh(multi(...)), sh(wsh(...)), sh(sortedmulti/multi(...)), plus single-sig wpkh/sh(wpkh)/pkh/tr, with key origins [fingerprint/48h/0h/0h/2h], xpub/Zpub/Ypub/tpub/Vpub keys, /0/* or /<0;1>/*, and an optional #checksum (verified).

  • Sparrow: open the wallet → Settings → Script Policy → Edit… (or Export… → Output Descriptor). Copy the text.
  • Specter: wallet → Settings → Export (Export to wallet software) - paste the JSON or the descriptor.
  • Nunchuk: wallet → ⋯ → Export wallet configuration (BSMS / descriptor file) - paste its contents.
  • Caravan: Download wallet configuration (JSON) - paste the JSON.
  • Electrum: Wallet → Information shows the master public keys; paste the wallet file JSON, or write the descriptor yourself.
  • Coldcard multisig config text (Policy: 2 of 3, Format: P2WSH, Derivation:, XFP: xpub lines) also works.

If an export is not recognised, paste the descriptor instead. Always click Show first addresses and check them against your wallet's receive addresses before scanning.

Advanced: use a different Electrum server

By default the app only talks to your Umbrel's Electrs (set by Umbrel). Any other server learns every address and balance of your cold storage. Only do this for a server you run yourself.

Watch-only. Saved keys are write-only: they are never shown again by this app. A descriptor/xpub holds only public keys: it cannot spend, and this app never builds or signs transactions. It is still privacy-sensitive (it reveals all your addresses and balances), so it is stored only in this app's /data volume and is never sent anywhere: addresses are derived locally and only script hashes go to the Electrum server above (your own Electrs).
